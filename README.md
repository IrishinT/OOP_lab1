# Лабораторные работы 1–2 (WPF)

Учебное WPF-приложение на .NET 8, доработанное с базового интерфейса (ЛР 1) до архитектуры MVVM с отдельной библиотекой ресурсов (ЛР 2).

## Структура решения

- `OOP_lab1` — основное приложение (View, ViewModel, Model, команды и сервисы).
- `ThemeLibrary` — библиотека ресурсов (палитра цветов, светлая и тёмная темы, переводы интерфейса, стили контролов).

## Что реализовано

- **Персонализация:** переключение светлой, тёмной и системной тем, выбор шрифта и его размера. Язык интерфейса переключается через `CodingSeb.Localization`. Доступны русский, английский, немецкий, французский, испанский, итальянский и украинский.
- **Стилизация:** все цвета, шрифты и стили элементов вынесены в `ThemeLibrary` и подключаются через ресурсы.
- **Таблицы (DataGrid):** `Ctrl+A` выделяет все строки, `Ctrl+C` копирует, `Ctrl+X` вырезает, `Ctrl+V` вставляет в активную таблицу, `Delete` удаляет выделение. Кнопка вставки показывает, в какую таблицу попадут строки. `Ctrl+Z` отменяет, а `Ctrl+Y` повторяет изменения данных в обеих таблицах. В полях ввода и при редактировании ячейки сочетания действуют на текст.
- **MVVM:** логика вынесена в `MainViewModel`, уведомление интерфейса через `INotifyPropertyChanged`, действия кнопок и меню — через `ICommand` (`RelayCommand`).
- **Вкладка привязок:** демонстрация `Binding.Mode` (`OneWay`, `TwoWay`, `OneTime`, `OneWayToSource`) и `UpdateSourceTrigger` (`PropertyChanged`, `LostFocus`, `Explicit`, `Default`).

## Запуск

1. Открыть `OOP_lab1.sln` в Visual Studio 2022 (требуется .NET 8.0 SDK и компонент разработки под WPF).
2. Нажать `F5` или выполнить в консоли:
   ```bash
   dotnet run --project OOP_lab1
   ```
